Mesh and NRP360 tests

Picks which monad answers a namespace (fresh, not itself, best score), agrees one value across several, and learns its scoring weights from outcomes.

Claims, commits and ledger65 tests

Claims are signed and kept, a commit is accepted only from the claim holder, memory replays into the same state, and usage is recorded in a signed ledger.

Authorization and gateway93 tests

A write needs a real signature over the real body from the right key; replays, other namespaces and reserved paths are refused.

Namespaces and hosts81 tests

A host resolves to one canonical namespace, and a name that is not the root never receives the root's content.

Security16 tests

A killed process never leaves a corrupt snapshot, one kernel owns a state directory, and /__monads refuses cross-origin calls.

Identity2 tests

A secret saved under an identity survives a restart, and the wrong password fails closed.

HTTP24 tests

The logs and OpenResty status proxies answer only for the configured namespace and only for the exact known paths.

Config and front end23 tests

A monad keeps its environment private, serves a built front end without shadowing NRP reads, and mounts the modules it is given.

Demos9 tests

A social graph served as a real namespace over HTTP: write fields and contacts, read whole branches back, and keep namespaces apart.
