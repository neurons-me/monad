# Namespace Resolution Protocol

The normative NRP spec lives on the NRP site, not in this repo.

- Latest normative spec: [NRP v0.3.0](https://neurons-me.github.io/NRP/v.0.3.0.html)
- Archived Phase 6 spec: [NRP v0.2.1](https://neurons-me.github.io/NRP/v.0.2.1.html)
- All versions and the next draft: [NRP home](https://neurons-me.github.io/NRP/)
- Current implementation report: [Mesh status](./Mesh/status.md)

`Mesh/status.md` describes what `monad.ai` currently implements. It is not the
protocol authority. The versioned NRP documents are the normative contract.
